# Ranma Card Game OCTGN image host

Machine-readable card artwork for the Ranma OCTGN project. Images are keyed by stable OCTGN set and card GUIDs. The production copy is served from Cloudflare R2 through `https://octgn-multi-game-feed.awesome-mole.workers.dev/assets/ranma/`; this repository remains a source backup. See `manifest.json` for URLs, checksums, versions, and pending artwork.
